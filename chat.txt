A static Cloudflare Pages site (public) + Pages Functions API (api) backed by a Cloudflare D1 database, in [c:\Users\itrosnt1\Desktop\Neuer Ordner](c:\Users\itrosnt1\Desktop\Neuer Ordner):

schema.sql — curated list of ~42 MCU movies/shows, ordered by in-universe chronology, tagged with an MCU phase (1–6) used purely for an Infinity-Stone color theme. Easy to edit/reorder.
items.js — public GET, returns the list + watched state.
toggle.js — POST to flip watched status. You protect this path with a Cloudflare Access policy so only approved emails can call it.
whoami.js — protected the same way; frontend calls it to decide whether to show edit controls.
index.html, style.css, app.js — dark space-themed UI, glowing "Infinity Gauntlet" progress stones (one per phase, fills/glows as you complete it), a vertical chronological timeline with phase-colored glowing cards and orb-style toggle checkboxes.
wrangler.toml, package.json — Pages + D1 binding config and npm scripts for local dev/deploy.
README.md — full step-by-step: create D1 db, migrate schema, deploy to Pages, attach your custom domain, and set up the Cloudflare Access policy on /api/toggle + /api/whoami (free Zero Trust plan, up to 50 users) so viewing stays public but editing is locked to you/your friends.
